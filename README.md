# 陕西省考 / 事业编 进面分查询

纯前端单页应用（SPA），用于查询**陕西省公务员**与**事业单位**公开招聘的进面分（资格复审各岗位最低分）、上岸笔试分、上岸综合分，支持多维筛选、收藏、CSV 导出与移动端访问。

## ✨ 功能特性

- **28725 条职位记录**：公务员 13996 + 事业编 14729，按招录年份独立存储。
- **三类分数，口径清晰区分**：
  - **进面分** = 资格复审表「各岗位最低分」（权威最终答案）
  - **上岸笔试分** = `min(最终录用人员笔试成绩)`，运行时计算
  - **上岸综合分** = `min(最终录用人员综合成绩)`
  - 三者关系：进面分 ≤ 上岸笔试分 ≤ 上岸综合分（多进面人岗三者必然不同）
- **多维筛选**：地区 / 年份 / 学历 / 类别 / 分数线范围 / 专业关键词（模糊匹配）。
- **收藏夹**：localStorage 持久化，可只看收藏。
- **CSV 导出**、按进面分排序。
- **移动端优先**：响应式布局；输入框字号统一 16px，**iOS Safari 聚焦不再自动放大**；统计区与操作按钮排版紧凑对齐。

## 🛠 技术栈

- 原生 JavaScript + 内联 CSS + SVG，**无构建步骤**。
- 数据以全局变量形式内置于 `web/data.js`（`window.JOBS=`）。
- 纯静态托管，可部署到任意静态服务器（当前线上：阿里云 ECS `http://121.40.208.54/gk/`）。

## 📁 目录结构

| 文件 | 说明 |
|------|------|
| `web/index.html` | 应用入口（含全部 HTML/CSS/JS） |
| `web/data.js` | 职位数据（约 17.9MB，单行 JSON 序列化） |
| `build_data.py` | 数据构建脚本（Excel → `data.js`） |
| `_verify_admit_v4.py` | 上岸分校验脚本（与 Excel 逐条比对） |
| `_fix_gaps_final.py` / `_fix_onboard.py` | 数据修复脚本 |
| `_deploy_ecs.py` | ECS 部署脚本（SSH 直传 + `systemctl restart`） |

## 🚀 本地运行

直接用浏览器打开 `web/index.html` 即可（需同目录下的 `web/data.js`）。

## 📦 部署

- **ECS**：使用 `_deploy_ecs.py`（SSH 流式直传 + 字节校验 + 重启 `cse_http` 服务）。
- **CloudStudio / 任意静态托管**：将 `web/` 目录整体托管，`index.html` 引用同目录 `data.js` 即可。

## ⚠️ 数据说明

- `web/data.js` 由原始 Excel 源表（`excel/` 目录，未入库）经 `build_data.py` 解析生成。
- 上岸分口径已与官方复审表逐条校验：公务员 4053/4053、事业编 4034/4034 全部比对通过，覆盖 100%。
- 部分岗位原始 `edu`（学历）字段为空，前端在学历筛选时将其视为「不限」，避免误过滤。
